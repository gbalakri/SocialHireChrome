Setup Guide

  1. In Salesforce Setup, search for App Manager and click New Connected App.
  2. Enable OAuth Settings. Add as a Callback URL.
  3. Add scopes: Manage user data via APIs (api) and Perform requests at any time (refresh_token).
  4. Save, wait ~10 minutes, then copy the Consumer Key into the field above.
  5. Click Save Settings, then Authorize with Salesforce in the popup.

Custom Field (Optional)

To store the LinkedIn URL in Salesforce, create a custom field called LinkedIn_URL__c (Text, 500) on Lead, Contact, and Account objects. Without it, everything still works — the LinkedIn URL field is simply ignored.
